# Mathematical research notes

The notes are grouped by mathematical role. Their filenames and mathematical
content were retained during the move; navigation links and paths to moved
artifacts were adjusted where needed.

## Lower bounds

Start with the [six-CNOT lower-bound record](lower_bounds/global_lower_bound6_complete_filter.md).
The [four-CNOT](lower_bounds/global_lower_bound4_spectral_path.md) and
[five-CNOT](lower_bounds/global_lower_bound5_spectral_gram.md) arguments are
inputs to that record. The `global_lower_bound7_*.md` files describe
additional support, schedule, and Gram investigations. They do not establish a
global seven-CNOT lower bound.

## Constructions

The [exact 14-CNOT derivation](constructions/topology14_exact_matchgate_derivation.md)
corresponds to the preserved rational gate list. The other
`algebraic*.md` and `topology*.md` files record earlier constructions or
structural calculations; compare any claim with the current
[status](../STATUS.md) and acceptance records before treating it as an
incumbent.

Historical script and output filenames mentioned in these notes generally
resolve under `archive/legacy_root/`. Current verification commands remain at
the repository root; use the [artifact index](../INDEX.md) to find them.
